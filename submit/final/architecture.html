📊 System Overview

This architecture shows the complete Longevity Narratives pipeline running on Ascend.io. Data flows from Snowflake (11,929 articles) and MediaCloud API (weekly new articles) through multiple processing layers (sentiment analysis, data cleaning, SQL analytics) to produce interactive dashboards and advocacy intelligence reports. The system is fully automated with weekly monitoring (Monday 9 AM UTC) and reporting (Friday 9 AM UTC).
